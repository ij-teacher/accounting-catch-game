老師登入／編輯共用題庫

對象：初學會計的學生。預設五大要素各 3 題；每回合將已發布題庫的全部題目打亂順序，每題玩一次。每題答對 10 分，不扣分；項目落到底部時，依目前選擇的接盤判定。作答後立即自動出下一題，下方保留上一題解說；完成本回合後顯示結果與錯題回顧。速度可選 5 秒或 8 秒，遊戲中也能調整。

題目採企業會計情境。「股本」以公司為例；費用均指本期已發生的費用。此版不涵蓋借貸法則、交易分錄或抵減科目。

老師登入後可修改題庫並發布給全班。請等畫面顯示「學生版已更新」（通常 1–2 分鐘），再請學生開啟網頁或開始新回合；進行中的回合不受影響。

老師第一次使用：到 GitHub 建立專用權杖，選擇「Only select repositories」→「accounting-catch-game」，將「Contents」設為「Read and write」。請勿使用 GitHub 登入密碼，也不要將權杖分享給學生。題庫內容會公開於本遊戲的 GitHub 儲存庫。

權杖僅用於此次編輯，不儲存在瀏覽器。重新整理或登出後需重新輸入。學生不需要登入。
